### CU-03 · Validar autenticación reforzada (MFA)

| **Módulo · Prioridad** | M01 · Acceso, Usuarios y Roles · Prioridad Crítica · Etapa 1 |
| --- | --- |
| **Actor primario** | Administrador |
| **Actores secundarios** | — |
| **Requisitos** | RF-01, RNF-06, RN-07 |
| **Descripción** | Exige un segundo factor de autenticación a las cuentas administrativas, al iniciar sesión y antes de cambiar el modo operacional. Es un caso de apoyo: lo activan CU-02 (extensión) y CU-04 (inclusión). |
| **Precondiciones** | El administrador ha ingresado credenciales válidas, o está solicitando una operación que exige verificación reforzada. El administrador tiene un segundo factor configurado. |
| **Disparador** | CU-02 detecta una cuenta administrativa o CU-04 solicita confirmar la identidad antes de cambiar el modo. |
| **Flujo principal** | **1.** El sistema solicita el segundo factor al administrador.  **2.** El administrador entrega el segundo factor.  **3.** El sistema valida que sea correcto, vigente y de un solo uso.  **4.** El sistema marca la verificación como satisfecha para la sesión u operación en curso.  **5.** El sistema devuelve el control al caso de uso que lo invocó. |
| **Flujos alternativos** | **A1** El administrador solicita un nuevo código o desafío cuando el anterior venció. |
| **Excepciones** | **E1** Segundo factor incorrecto o vencido: el sistema permite reintentar un número limitado de veces.  **E2** Intentos agotados: el sistema bloquea la operación y registra el evento (CU-05).  **E3** El servicio del segundo factor no está disponible: la operación crítica no se autoriza. |
| **Postcondiciones** | La operación crítica puede continuar solo si el segundo factor fue validado. |
| **Reglas de negocio** | RN-07: MFA obligatorio para permisos de administración. El mecanismo concreto del segundo factor se define en el documento 07. |
| **Relaciones** | «extend» de CU-02 (cuenta administrativa). «include» desde CU-04 (siempre). |
| **Criterios de aceptación** | No es posible cambiar el modo operacional sin una verificación reforzada válida. |
