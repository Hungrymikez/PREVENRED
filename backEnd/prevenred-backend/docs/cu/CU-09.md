### CU-09 · Consultar registros de auditoría

| **Módulo · Prioridad** | M04 · Auditoría y Trazabilidad · Prioridad Crítica · Etapa 1 y 3 |
| --- | --- |
| **Actor primario** | Administrador |
| **Actores secundarios** | — |
| **Requisitos** | RF-05, RN-02 |
| **Descripción** | Permite revisar la trazabilidad de eventos críticos de seguridad, administración, inspección, ayudas y cambios de modo, y exportarla con control de permisos. |
| **Precondiciones** | El administrador tiene sesión vigente y permiso para consultar la auditoría. |
| **Disparador** | El administrador abre la pantalla «Auditoría» del dashboard. |
| **Flujo principal** | **1.** El sistema muestra los registros más recientes.  **2.** El administrador define filtros: fecha, actor, tipo de evento y recurso.  **3.** El sistema consulta y presenta los resultados paginados.  **4.** El administrador abre el detalle de un registro.  **5.** El sistema muestra actor, fecha y hora, acción, recurso, resultado y estado anterior y nuevo. |
| **Flujos alternativos** | **A1** Exportar: el administrador solicita exportar la consulta; el sistema verifica permisos, genera el archivo y registra la exportación.  **A2** Sin resultados: el sistema lo informa y sugiere ampliar los filtros. |
| **Excepciones** | **E1** Usuario sin permiso: el sistema niega el acceso.  **E2** La consulta es demasiado amplia: el sistema pide acotar el rango. |
| **Postcondiciones** | La consulta no modifica ningún registro. |
| **Reglas de negocio** | Los registros de auditoría no se editan ni se eliminan desde la aplicación. La consulta y la exportación de la auditoría se registran como accesos administrativos. |
| **Relaciones** | Consulta lo generado por CU-05. |
| **Criterios de aceptación** | El administrador filtra por rango de fechas y tipo de evento y ve registros completos; ningún usuario puede modificarlos. |
