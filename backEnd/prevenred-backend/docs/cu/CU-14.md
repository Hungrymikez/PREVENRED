### CU-14 · Gestionar reservas de mis herramientas

| **Módulo · Prioridad** | M06 · SegundaVida Pereira · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano (propietario) |
| **Actores secundarios** | — |
| **Requisitos** | RF-08 |
| **Descripción** | Permite al propietario de una herramienta aceptar o rechazar solicitudes y registrar la entrega y la devolución. |
| **Precondiciones** | El usuario tiene herramientas publicadas en alquiler. Existe al menos una solicitud o reserva (CU-13). |
| **Disparador** | El propietario abre «Mis herramientas» o recibe el aviso de una solicitud. |
| **Flujo principal** | **1.** El sistema lista las solicitudes y reservas con su estado.  **2.** El propietario abre una solicitud pendiente y revisa fechas, costo y datos del solicitante.  **3.** El propietario la acepta.  **4.** El sistema confirma la reserva y notifica al solicitante.  **5.** Llegada la fecha, el propietario registra la entrega.  **6.** Al finalizar, el propietario registra la devolución y el estado en que se recibió la herramienta.  **7.** El sistema marca la transacción como completada y habilita la calificación (CU-15). |
| **Flujos alternativos** | **A1** El propietario rechaza la solicitud indicando un motivo; el sistema notifica al solicitante.  **A2** Cancelación de una reserva aceptada: el sistema libera las fechas y notifica a la contraparte. |
| **Excepciones** | **E1** La solicitud ya fue cancelada por el solicitante: el sistema lo informa.  **E2** Conflicto de fechas con otra reserva: el sistema impide aceptar ambas. |
| **Postcondiciones** | La reserva queda con su estado actualizado (aceptada, entregada, devuelta o cancelada). La transacción completada habilita calificaciones. |
| **Reglas de negocio** | No existen depósitos de garantía ni resolución formal de disputas en la v1.0. Los estados de la reserva quedan en el historial. |
| **Relaciones** | Responde a CU-13. Habilita CU-15. |
| **Criterios de aceptación** | Un propietario acepta una solicitud, registra la entrega y la devolución, y la reserva termina como completada. |
