### CU-19 · Buscar servicios técnicos

| **Módulo · Prioridad** | M07 · OficiosYa Pereira · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | — |
| **Requisitos** | RF-11, RNF-03 |
| **Descripción** | Permite buscar técnicos verificados por texto libre y por filtros de especialidad, zona, valoración y disponibilidad. |
| **Precondiciones** | El usuario tiene sesión vigente. Existen técnicos en estado «Verificado». |
| **Disparador** | El usuario abre OficiosYa. |
| **Flujo principal** | **1.** El usuario escribe lo que necesita arreglar o elige una especialidad.  **2.** El usuario aplica filtros: zona, valoración y disponibilidad.  **3.** El sistema consulta los técnicos verificados que cumplen los criterios.  **4.** El sistema muestra los resultados en lista y en mapa, con insignia, calificación, zona y disponibilidad.  **5.** El usuario abre el perfil de un técnico.  **6.** El usuario elige una acción: pedir cotización (CU-20) o contactar por WhatsApp (CU-22). |
| **Flujos alternativos** | **A1** Contactar por WhatsApp: se ejecuta CU-22 si el usuario autoriza el contacto. |
| **Excepciones** | **E1** Sin resultados: el sistema sugiere ampliar la zona o cambiar la especialidad.  **E2** El servicio de mapas no está disponible: el sistema muestra solo la lista. |
| **Postcondiciones** | El usuario conoce los técnicos disponibles y puede iniciar una solicitud. |
| **Reglas de negocio** | Solo los técnicos con estado «Verificado» aparecen en los resultados. Los planes pagos no alteran la selección de técnicos movilizados en emergencia. |
| **Relaciones** | «extend» desde CU-22 (WhatsApp). Continúa en CU-20. |
| **Criterios de aceptación** | Un ciudadano filtra técnicos por especialidad y zona y solo ve perfiles verificados. |
