### CU-21 · Responder cotización

| **Módulo · Prioridad** | M07 · OficiosYa Pereira · Prioridad Media · Etapa 2 |
| --- | --- |
| **Actor primario** | Técnico / Voluntario |
| **Actores secundarios** | — |
| **Requisitos** | RF-12 |
| **Descripción** | Permite al técnico revisar la evidencia recibida y enviar su propuesta de valor al ciudadano. |
| **Precondiciones** | El técnico está verificado y tiene sesión vigente. Recibió una solicitud de cotización (CU-20). |
| **Disparador** | El técnico recibe la notificación de una solicitud o la abre desde su bandeja. |
| **Flujo principal** | **1.** El técnico abre la solicitud.  **2.** El técnico revisa la descripción y la evidencia.  **3.** El técnico ingresa el valor propuesto y las condiciones del trabajo.  **4.** El técnico envía la propuesta.  **5.** El sistema registra la respuesta y notifica al ciudadano. |
| **Flujos alternativos** | **A1** El técnico declina la solicitud indicando un motivo; el sistema lo notifica al ciudadano. |
| **Excepciones** | **E1** La solicitud fue cancelada por el ciudadano: el sistema lo informa al técnico.  **E2** La evidencia no puede visualizarse: el sistema permite reintentar la carga o pedir una nueva. |
| **Postcondiciones** | La solicitud queda respondida o declinada. |
| **Reglas de negocio** | La propuesta es informativa: la contratación y el pago se acuerdan fuera de la plataforma. |
| **Relaciones** | Responde a CU-20. |
| **Criterios de aceptación** | El técnico envía su propuesta y el ciudadano la ve asociada a su solicitud. |
