### CU-23 · Responder encuesta de bienestar

| **Módulo · Prioridad** | M08 · Mente Resiliente · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | — |
| **Requisitos** | RF-14, RF-16, RN-03, RN-05, RNF-04 |
| **Descripción** | Permite enviar un registro de bienestar (nivel de ánimo y texto opcional) para el análisis comunitario agregado por barrio. No juzga, rastrea ni diagnostica a la persona. |
| **Precondiciones** | El usuario tiene sesión vigente. Existe un aviso de privacidad vigente. |
| **Disparador** | El usuario abre «Mente Resiliente». |
| **Flujo principal** | **1.** El sistema verifica el consentimiento vigente del usuario; si no existe, ejecuta CU-24.  **2.** El sistema muestra el mensaje de que la respuesta se analiza junto con la de otros vecinos, por barrio, sin nombre y sin ser un diagnóstico.  **3.** El usuario elige su nivel de ánimo en la escala de cinco niveles (Muy bien, Bien, Regular, Mal, Muy mal).  **4.** El usuario escribe un texto libre (opcional).  **5.** El usuario confirma el envío.  **6.** El sistema almacena la respuesta con el barrio o la comuna y la fecha, aplicando minimización de datos.  **7.** El sistema confirma el envío y muestra el acceso a apoyo profesional (CU-27).  **8.** El análisis posterior se realiza en CU-25. |
| **Flujos alternativos** | **A1** El sistema detecta una expresión de crisis: se activa el flujo de atención (CU-28) sin presentar el resultado como diagnóstico (ver observación O-06).  **A2** El usuario omite el texto y envía solo el nivel de ánimo.  **A3** El usuario ya envió su registro de la semana: el comportamiento se define en el diseño (ver observación O-08). |
| **Excepciones** | **E1** El usuario no otorga el consentimiento: no se recopila la respuesta (CU-24, A1).  **E2** Sin conectividad: el sistema informa que el envío requiere conexión (Mente Resiliente no opera sin conexión en la v1.0). |
| **Postcondiciones** | La respuesta queda registrada sin exponer la identidad del usuario en el análisis ni en el dashboard (ver observación O-07). |
| **Reglas de negocio** | RN-03: los resultados del NLP se usan solo de forma agregada, nunca como diagnóstico individual. Los datos de Mente Resiliente nunca se usan con fines comerciales. |
| **Relaciones** | «include» CU-24 (consentimiento). «extend» desde CU-28 si hay expresión de crisis. Sus textos los analiza CU-25. |
| **Criterios de aceptación** | Un ciudadano envía su registro tras aceptar el aviso y el sistema confirma sin mostrar diagnóstico alguno. |
