### CU-24 · Otorgar consentimiento y aceptar aviso de privacidad

| **Módulo · Prioridad** | M08 y M01 · Mente Resiliente / Acceso, Usuarios y Roles · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | — |
| **Requisitos** | RF-14, RN-05 |
| **Descripción** | Informa al usuario las finalidades, los datos recolectados, la conservación y los canales de atención, y registra su consentimiento antes de recopilar una respuesta de bienestar. |
| **Precondiciones** | El usuario inició CU-23 y no tiene un consentimiento vigente para la versión actual del aviso. |
| **Disparador** | CU-23 solicita el consentimiento. |
| **Flujo principal** | **1.** El sistema presenta el aviso de privacidad con finalidades, datos recolectados, conservación y canales de atención.  **2.** El usuario lo lee y acepta.  **3.** El sistema registra el consentimiento (versión del aviso, fecha y hora).  **4.** El sistema devuelve el control a CU-23. |
| **Flujos alternativos** | **A1** El usuario no acepta: CU-23 no continúa; no se sanciona al usuario y puede acceder a apoyo profesional (CU-27).  **A2** Ya existe un consentimiento vigente: el caso no se muestra, salvo que cambie la versión del aviso. |
| **Excepciones** | **E1** No se puede registrar el consentimiento: el sistema no recopila datos y permite reintentar. |
| **Postcondiciones** | El consentimiento queda registrado con su versión y fecha. |
| **Reglas de negocio** | RN-05: finalidad, minimización, seguridad, acceso restringido y conservación limitada. Se requiere base legal y aviso de privacidad antes de recopilar textos (RF-14). |
| **Relaciones** | «include» desde CU-23. |
| **Criterios de aceptación** | No se recopila ninguna respuesta de bienestar sin un consentimiento registrado. |
