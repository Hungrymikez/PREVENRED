### CU-29 · Reportar daño en vivienda

| **Módulo · Prioridad** | M09 · Reporte de Incidentes y Solicitudes de Ayuda · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | Almacenamiento de archivos; GPS / Mapas |
| **Requisitos** | RF-22, RNF-01, RNF-08, RNF-10, RN-04 |
| **Descripción** | Permite reportar el daño en una vivienda indicando el tipo, una foto y la ubicación, en tres pasos. Genera un identificador de caso. El reporte no es una clasificación oficial de habitabilidad. |
| **Precondiciones** | El Modo Emergencia está activo. El usuario tiene sesión vigente. |
| **Disparador** | El usuario pulsa «Reportar daño en vivienda» en la pantalla de emergencia. |
| **Flujo principal** | **1.** Paso 1: el usuario elige el tipo de daño (grietas en muros, techo o losa caída, vivienda inclinada u otro).  **2.** Paso 2: el usuario adjunta una foto mediante CU-47.  **3.** Paso 3: el sistema obtiene la ubicación por GPS (CU-48), el usuario la confirma o la corrige y pulsa «Enviar reporte».  **4.** El sistema valida los datos y genera un identificador único de seguimiento.  **5.** El sistema registra el caso en estado «Reportado» y lo hace visible al coordinador.  **6.** El sistema confirma al usuario con el identificador y el aviso de que el reporte no es una clasificación oficial. |
| **Flujos alternativos** | **A1** Sin conectividad: el reporte se guarda cifrado en el dispositivo y se envía al reconectar (ver observación O-02).  **A2** El GPS no está disponible: el usuario marca la ubicación manualmente en el mapa. |
| **Excepciones** | **E1** La foto no puede adjuntarse: el sistema informa el problema (ver observación O-13).  **E2** Falla el envío: el reporte se conserva para reintento.  **E3** El Modo Emergencia no está activo: la función no está disponible. |
| **Postcondiciones** | Existe un caso con identificador único en estado «Reportado», con tipo de daño, foto y ubicación. El ciudadano puede consultarlo (CU-32). |
| **Reglas de negocio** | Máximo 3 interacciones principales desde la pantalla de emergencia (RNF-10). Un reporte ciudadano no es una clasificación oficial: un inspector autorizado evalúa la vivienda (RN-04). |
| **Relaciones** | «include» CU-47 y CU-48. Alimenta CU-39 y, tras la validación, CU-34. |
| **Criterios de aceptación** | Con el Modo Emergencia activo, un ciudadano reporta un daño en tres pasos y recibe un identificador de caso. El caso aparece en el tablero del coordinador. |
