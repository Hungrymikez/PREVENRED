### CU-30 · Reportar vía bloqueada o escombros

| **Módulo · Prioridad** | M09 · Reporte de Incidentes y Solicitudes de Ayuda · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | Almacenamiento de archivos; GPS / Mapas |
| **Requisitos** | RF-23, RF-22, RNF-01, RNF-08, RNF-10 |
| **Descripción** | Permite reportar bloqueos de vías, deslizamientos, árboles caídos y otros incidentes con ubicación, fotografía y descripción. |
| **Precondiciones** | El Modo Emergencia está activo. El usuario tiene sesión vigente. |
| **Disparador** | El usuario pulsa «Reportar vía bloqueada» en la pantalla de emergencia. |
| **Flujo principal** | **1.** El usuario elige el tipo de incidente (bloqueo, deslizamiento, árbol caído u otro).  **2.** El sistema obtiene la ubicación mediante CU-48; el usuario la confirma o la corrige.  **3.** El usuario adjunta una fotografía mediante CU-47.  **4.** El usuario agrega una descripción breve.  **5.** El usuario envía el reporte.  **6.** El sistema genera un identificador de caso y lo registra en estado «Reportado».  **7.** El sistema confirma al usuario con el identificador. |
| **Flujos alternativos** | **A1** Sin conectividad: el reporte se guarda localmente y se sincroniza al reconectar (ver observación O-02).  **A2** El sistema marca el reporte como posible duplicado por cercanía y tipo, para revisión del coordinador (CU-39). |
| **Excepciones** | **E1** El GPS no está disponible: el usuario ubica el incidente manualmente en el mapa.  **E2** Falla el envío: el reporte se conserva para reintento. |
| **Postcondiciones** | El incidente queda registrado con identificador, ubicación, foto y descripción y es visible en el mapa. |
| **Reglas de negocio** | Debe completarse en máximo 3 interacciones principales (RNF-10). El ciclo de vida del incidente se registra con fecha y responsable (RF-24). |
| **Relaciones** | «include» CU-47 y CU-48. Alimenta CU-39 y CU-40. |
| **Criterios de aceptación** | Un ciudadano reporta un deslizamiento con ubicación, foto y descripción y el caso aparece con un identificador único. |
