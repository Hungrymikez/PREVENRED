### CU-34 · Registrar censo de inmueble

| **Módulo · Prioridad** | M10 · Censo de Inmuebles e Inspección · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Inspector |
| **Actores secundarios** | Almacenamiento de archivos; GPS / Mapas |
| **Requisitos** | RF-19, RF-22, RNF-08, RN-05, RN-06 |
| **Descripción** | Permite al inspector capturar el censo digital de un inmueble: dirección, coordenadas, fotografías, características, número de residentes y los campos del protocolo oficial. |
| **Precondiciones** | El Modo Emergencia está activo. El inspector tiene sesión vigente y, si corresponde, una asignación (CU-38). |
| **Disparador** | El inspector pulsa «Nuevo censo» o abre una asignación. |
| **Flujo principal** | **1.** El sistema obtiene la ubicación mediante CU-48; el inspector la confirma o la corrige.  **2.** El inspector registra la dirección del inmueble.  **3.** El inspector registra las características del inmueble y el número de residentes.  **4.** El inspector adjunta fotografías mediante CU-47.  **5.** El inspector completa los campos definidos por el protocolo oficial.  **6.** El inspector guarda el censo.  **7.** El sistema valida los campos obligatorios y asocia el censo a un identificador de caso (el del reporte ciudadano, si existe).  **8.** El sistema registra el inmueble como censado y actualiza el contador del dashboard. |
| **Flujos alternativos** | **A1** Sin conectividad: el censo se guarda localmente cifrado y se sincroniza al reconectar (CU-37).  **A2** El inmueble ya fue censado (misma dirección o coordenadas): el sistema avisa y ofrece actualizar el registro existente. |
| **Excepciones** | **E1** Faltan campos obligatorios del protocolo: el sistema no permite guardar.  **E2** El GPS no está disponible: el inspector marca la ubicación manualmente.  **E3** La carga de fotografías falla: el sistema conserva el censo y reintenta la carga. |
| **Postcondiciones** | El inmueble queda censado con su ubicación, evidencias y datos del protocolo. El contador de «Viviendas censadas» se actualiza. |
| **Reglas de negocio** | Fotografías y documentos se almacenan con control de acceso y retención (RN-06). Se registra solo el número de residentes, no sus datos personales (RN-05). |
| **Relaciones** | «include» CU-47 y CU-48. «extend» desde CU-37 si no hay conectividad. Se evalúa en CU-36. |
| **Criterios de aceptación** | Un inspector completa el formulario de campo, lo guarda sin conexión y lo sincroniza sin duplicados. |
