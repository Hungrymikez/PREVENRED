### CU-35 · Clasificar nivel de daño

| **Módulo · Prioridad** | M10 · Censo de Inmuebles e Inspección · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Inspector |
| **Actores secundarios** | — |
| **Requisitos** | RF-20, RF-21, RN-04 |
| **Descripción** | Asigna el nivel de daño de un inmueble usando el catálogo oficial vigente. El sistema registra la clasificación del inspector; no decide por sí solo la habitabilidad. |
| **Precondiciones** | El inspector está ejecutando CU-36. El catálogo oficial de daños está cargado (CU-10). |
| **Disparador** | CU-36 solicita la clasificación del daño. |
| **Flujo principal** | **1.** El sistema presenta los niveles del catálogo oficial vigente.  **2.** El inspector, con base en su evaluación y las evidencias, selecciona el nivel de daño.  **3.** El inspector registra observaciones.  **4.** El sistema valida que el nivel pertenezca al catálogo vigente.  **5.** El sistema asocia el nivel al inmueble y devuelve el control a CU-36. |
| **Flujos alternativos** | **A1** Caso crítico: el sistema marca el caso para una segunda revisión por un usuario autorizado. |
| **Excepciones** | **E1** El catálogo no está cargado o está inactivo: el sistema no permite clasificar e informa al administrador.  **E2** El nivel seleccionado fue desactivado: el sistema pide elegir uno vigente. |
| **Postcondiciones** | El inmueble tiene un nivel de daño asociado a la versión del catálogo con la que fue clasificado. |
| **Reglas de negocio** | Las etiquetas las define y valida la autoridad competente. El sistema no decide por sí solo la habitabilidad (RN-04). |
| **Relaciones** | «include» desde CU-36. Usa el catálogo de CU-10. |
| **Criterios de aceptación** | La clasificación usa únicamente niveles del catálogo oficial vigente. |
