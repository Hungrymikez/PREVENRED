### CU-36 · Ejecutar flujo de habitabilidad

| **Módulo · Prioridad** | M10 · Censo de Inmuebles e Inspección · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Inspector |
| **Actores secundarios** | Almacenamiento de archivos |
| **Requisitos** | RF-21, RF-20, RF-05, RNF-08, RN-04 |
| **Descripción** | Guía al inspector por el procedimiento oficial de inspección y registra el resultado: habitable, restringido o no habitable, o evacuación, según el protocolo vigente. |
| **Precondiciones** | El inspector tiene rol autorizado y sesión vigente. Existe una inspección asignada (CU-38) o un inmueble en censo (CU-34). El protocolo oficial está configurado. |
| **Disparador** | El inspector abre una inspección asignada. |
| **Flujo principal** | **1.** El sistema muestra el formulario guiado según el procedimiento oficial.  **2.** El inspector recorre los pasos del procedimiento y captura las evidencias fotográficas.  **3.** El sistema ejecuta CU-35 para clasificar el nivel de daño.  **4.** El sistema presenta las rutas posibles: habitable, restringido o no habitable, y evacuación.  **5.** El inspector selecciona el resultado según el protocolo vigente y lo confirma.  **6.** El sistema registra el resultado con el inspector responsable, la fecha y la hora.  **7.** El sistema registra el evento en auditoría (CU-05).  **8.** El sistema actualiza el estado del caso y los contadores del dashboard, y el ciudadano puede ver el estado autorizado (CU-32). |
| **Flujos alternativos** | **A1** Sin conectividad: el avance se guarda localmente cifrado y se sincroniza al reconectar (CU-37).  **A2** Resultado de evacuación: queda visible de inmediato para el coordinador en el dashboard.  **A3** Caso crítico: se aplica la segunda revisión definida en CU-35 (A1). |
| **Excepciones** | **E1** El usuario no tiene rol autorizado: el sistema niega la acción.  **E2** El protocolo oficial no está configurado: el sistema no permite cerrar la inspección.  **E3** La inspección está incompleta: el sistema no permite confirmar el resultado.  **E4** Falla el registro de auditoría: el resultado no se confirma. |
| **Postcondiciones** | El resultado de la inspección queda registrado y auditado. El caso refleja el nuevo estado. |
| **Reglas de negocio** | Las decisiones de habitabilidad corresponden a un procedimiento técnico aprobado y a un usuario con rol autorizado (RN-04). El sistema asiste la captura; la decisión siempre es humana. |
| **Relaciones** | «include» CU-35 y CU-05. «extend» desde CU-37 si no hay conectividad. Las evidencias se adjuntan según CU-47 (ver observación O-04). |
| **Criterios de aceptación** | Un inspector completa el formulario, lo guarda sin conexión y lo sincroniza; la clasificación usa el catálogo y el protocolo aprobados. |
