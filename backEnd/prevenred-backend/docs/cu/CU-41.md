### CU-41 · Gestionar banco de ayudas

| **Módulo · Prioridad** | M12 · Banco de Ayudas y Matching · Prioridad Alta · Etapa 3 |
| --- | --- |
| **Actor primario** | Administrador |
| **Actores secundarios** | — |
| **Requisitos** | RF-26, RF-27, RF-05 |
| **Descripción** | Permite convertir inventarios de materiales y herramientas de SegundaVida en ofertas de ayuda mediante reglas configurables, conservando la trazabilidad de su origen, y controlar el inventario de ayudas. |
| **Precondiciones** | El Modo Emergencia está activo. Hay inventarios en SegundaVida (CU-11) o ofertas directas (CU-33). |
| **Disparador** | El administrador abre «Banco de ayudas» en el dashboard. |
| **Flujo principal** | **1.** El sistema muestra las ofertas disponibles (de SegundaVida y directas) y las necesidades abiertas.  **2.** El administrador configura o selecciona las reglas de conversión de inventarios en oferta de ayuda.  **3.** El sistema aplica las reglas y crea las ofertas, manteniendo el vínculo con la publicación de origen.  **4.** El administrador revisa las ofertas, ajusta cantidades y estado y valida las donaciones.  **5.** El sistema actualiza el control de inventario: disponible, comprometido y entregado.  **6.** El sistema registra los eventos de donación en auditoría. |
| **Flujos alternativos** | **A1** El administrador modifica las reglas de conversión: se aplican a nuevas conversiones.  **A2** El administrador excluye una oferta o un ítem de la conversión (ver observación O-09). |
| **Excepciones** | **E1** Oferta sin datos mínimos: el sistema pide completarlos.  **E2** Ítem ya asignado o entregado: el sistema no permite editarlo.  **E3** Inconsistencia de inventario: el sistema impide guardar cantidades negativas. |
| **Postcondiciones** | Las ofertas quedan registradas con su origen y su inventario controlado. |
| **Reglas de negocio** | No se cobran comisiones en Modo Emergencia. Toda donación queda en la auditoría (ver observación O-03). No se gestionan donaciones monetarias. |
| **Relaciones** | Toma inventario de CU-11 y ofertas de CU-33. Alimenta CU-42. |
| **Criterios de aceptación** | Un inventario de SegundaVida se convierte en oferta de ayuda manteniendo su origen. |
