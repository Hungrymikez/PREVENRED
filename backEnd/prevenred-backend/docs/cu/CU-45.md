### CU-45 · Consultar dashboard municipal

| **Módulo · Prioridad** | M14 · Dashboard Municipal y Reportes · Prioridad Alta · Etapa 3 |
| --- | --- |
| **Actor primario** | Administrador |
| **Actores secundarios** | — |
| **Requisitos** | RF-29, RF-17, RF-24, RF-25, RNF-02 |
| **Descripción** | Permite ver en tiempo real los indicadores de la operación: viviendas censadas, estados de daño, casos, inventarios, incidentes viales y voluntarios movilizados. En Modo Cotidiano muestra uso y bienestar. |
| **Precondiciones** | El administrador tiene sesión vigente. |
| **Disparador** | El administrador abre el dashboard municipal. |
| **Flujo principal** | **1.** El sistema muestra el banner del estado operacional y la hora de la última actualización.  **2.** El sistema presenta las tarjetas de indicadores: viviendas censadas, casos abiertos, incidentes viales con bloqueo activo y voluntarios movilizados.  **3.** El sistema muestra el mapa embebido y la lista de incidentes recientes (identificador, comuna o barrio, descripción y estado).  **4.** El administrador aplica filtros o navega a un módulo desde el menú lateral.  **5.** El sistema actualiza los datos en el intervalo definido por el diseño. |
| **Flujos alternativos** | **A1** Cambiar el modo desde el tablero: se ejecuta CU-04.  **A2** Exportar un reporte: se ejecuta CU-46.  **A3** Abrir un incidente: lleva a CU-39. |
| **Excepciones** | **E1** Una fuente de datos no responde: el indicador muestra «sin datos» con la hora de su última actualización.  **E2** Los datos están desactualizados: el sistema lo advierte. |
| **Postcondiciones** | El administrador tiene una visión única y actualizada de la operación. |
| **Reglas de negocio** | Los indicadores de bienestar solo se muestran de forma agregada. El intervalo de actualización se define en el diseño (ver observación O-16). |
| **Relaciones** | «extend» desde CU-46 (exportar). Consume datos de CU-34 a CU-44 y se apoya en CU-40. |
| **Criterios de aceptación** | Los indicadores se actualizan dentro del intervalo definido y reflejan su fuente de datos. |
