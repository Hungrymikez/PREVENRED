### CU-46 · Exportar reportes oficiales

| **Módulo · Prioridad** | M14 · Dashboard Municipal y Reportes · Prioridad Alta · Etapa 3 |
| --- | --- |
| **Actor primario** | Administrador |
| **Actores secundarios** | — |
| **Requisitos** | RF-30, RN-05 |
| **Descripción** | Genera reportes oficiales en PDF y Excel/CSV con fecha de corte, filtros utilizados y metadatos de generación, según los permisos del rol. |
| **Precondiciones** | El administrador tiene sesión vigente y permiso de exportación. Hay datos disponibles en el dashboard. |
| **Disparador** | El administrador pulsa «Exportar» en el dashboard. |
| **Flujo principal** | **1.** El administrador elige el reporte o los indicadores.  **2.** El administrador elige el formato (PDF o Excel/CSV), los filtros y la fecha de corte.  **3.** El sistema valida los permisos del rol.  **4.** El sistema genera el reporte con los datos, los filtros, la fecha de corte y los metadatos de generación.  **5.** El sistema entrega el archivo para su descarga.  **6.** El sistema registra quién generó el reporte. |
| **Flujos alternativos** | **A1** El administrador cancela antes de generar: no se produce ningún archivo. |
| **Excepciones** | **E1** Usuario sin permiso: el sistema niega la exportación.  **E2** No hay datos para los filtros: el sistema lo informa.  **E3** Falla la generación: el sistema permite reintentar. |
| **Postcondiciones** | Se obtiene un reporte oficial con trazabilidad de quién y cuándo lo generó. |
| **Reglas de negocio** | La exportación respeta los permisos del rol y registra quién la generó. Los indicadores de bienestar solo se exportan agregados. |
| **Relaciones** | «extend» de CU-45 (a solicitud del administrador, según permisos). |
| **Criterios de aceptación** | Un reporte exportado incluye fecha de corte, filtros y metadatos de generación. |
