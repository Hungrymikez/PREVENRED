### CU-48 · Obtener ubicación

| **Módulo · Prioridad** | M11 · Mapa Multicapa · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Sistema (invocado por otros casos de uso) |
| **Actores secundarios** | GPS / Mapas |
| **Requisitos** | RF-07, RF-19, RF-23, RNF-03, RN-05 |
| **Descripción** | Obtiene las coordenadas del dispositivo con permiso explícito y permite al usuario corregirlas. Es un caso de apoyo de la búsqueda de materiales, los reportes y el censo. |
| **Precondiciones** | Un caso invocante requiere una ubicación. El dispositivo tiene un sensor de ubicación o permite marcar un punto en el mapa. |
| **Disparador** | CU-12, CU-29, CU-30 o CU-34 solicitan la ubicación. |
| **Flujo principal** | **1.** El sistema solicita el permiso de ubicación si aún no fue concedido.  **2.** El usuario concede el permiso.  **3.** El sistema obtiene las coordenadas del dispositivo.  **4.** El sistema muestra la posición en el mapa con su precisión.  **5.** El usuario la confirma o la corrige moviendo el marcador o buscando una dirección.  **6.** El sistema devuelve las coordenadas al caso invocante. |
| **Flujos alternativos** | **A1** El usuario niega el permiso: puede marcar la ubicación manualmente en el mapa o indicar una dirección.  **A2** Precisión baja: el sistema lo advierte y sugiere corregir.  **A3** Ubicación aproximada (publicaciones de SegundaVida): el sistema reduce la precisión antes de guardarla. |
| **Excepciones** | **E1** El sensor de ubicación está desactivado: el sistema pide activarlo o usar la ubicación manual.  **E2** El servicio de mapas no está disponible: el sistema usa el caché controlado o guarda las coordenadas sin el mapa. |
| **Postcondiciones** | El caso invocante recibe unas coordenadas confirmadas por el usuario. |
| **Reglas de negocio** | Se requiere permiso explícito del usuario. La ubicación precisa solo la ven los roles autorizados (RN-05). |
| **Relaciones** | «include» desde CU-12, CU-29, CU-30 y CU-34. Se sugiere sumarlo a CU-31, CU-33 y CU-44 (ver observación O-05). |
| **Criterios de aceptación** | El usuario concede el permiso, ve su posición en el mapa y puede corregirla antes de confirmarla. |
