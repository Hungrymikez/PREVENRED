### CU-01 · Registrarse

| **Módulo · Prioridad** | M01 · Acceso, Usuarios y Roles · Prioridad Crítica · Etapa 1 |
| --- | --- |
| **Actor primario** | Ciudadano; Técnico / Voluntario |
| **Actores secundarios** | — |
| **Requisitos** | RF-03, RNF-06, RNF-14, RN-05 |
| **Descripción** | Permite a una persona crear una cuenta de Ciudadano o de Técnico / Voluntario con los datos mínimos necesarios, aceptando el aviso de privacidad y los términos de uso. Las cuentas de Inspector y de Administrador no se auto-registran: las crea un Administrador (CU-08). |
| **Precondiciones** | La persona no tiene una cuenta activa en la plataforma. El dispositivo tiene conectividad (el registro es una operación en línea). |
| **Disparador** | La persona selecciona «Crear cuenta» en la pantalla de acceso. |
| **Flujo principal** | **1.** La persona elige el tipo de cuenta: Ciudadano o Técnico / Voluntario.  **2.** El sistema muestra el formulario con los datos mínimos: identidad, medio de contacto, barrio o comuna (ubicación aproximada) y credenciales de acceso.  **3.** La persona diligencia el formulario.  **4.** El sistema valida el formato de los datos y que el medio de contacto no esté ya registrado.  **5.** El sistema presenta el aviso de privacidad y los términos de uso; la persona los acepta.  **6.** El sistema crea la cuenta con el rol elegido y registra la aceptación (versión del aviso, fecha y hora).  **7.** Si el rol es Técnico / Voluntario, el sistema crea un perfil en estado «Pendiente» de verificación y sugiere completarlo (CU-17).  **8.** El sistema confirma el registro y lleva a la persona al inicio de sesión (CU-02). |
| **Flujos alternativos** | **A1** La persona no acepta el aviso de privacidad o los términos: el sistema no crea la cuenta y explica que son necesarios para usar la plataforma.  **A2** Registro como Técnico / Voluntario: mientras el perfil esté «Pendiente» no aparece en OficiosYa ni puede ser movilizado como técnico verificado (CU-18). |
| **Excepciones** | **E1** El medio de contacto ya está registrado: el sistema lo informa y ofrece recuperar el acceso (CU-02, A2).  **E2** Datos inválidos o incompletos: el sistema marca los campos con error y conserva lo ya escrito.  **E3** Sin conectividad: el sistema informa que el registro requiere conexión.  **E4** Demasiados intentos desde un mismo origen: el sistema aplica limitación de frecuencia y pide reintentar más tarde (RNF-14). |
| **Postcondiciones** | Existe una cuenta con rol asignado y credenciales protegidas. La aceptación del aviso de privacidad y de los términos queda registrada. |
| **Reglas de negocio** | RN-05: solo se piden los datos necesarios para la finalidad (minimización). No existe auto-registro para los roles Inspector y Administrador. |
| **Relaciones** | Habilita el acceso a CU-02. Un registro Técnico / Voluntario conduce a CU-17 y CU-18. |
| **Criterios de aceptación** | Una persona se registra como Ciudadano y solo accede a las funciones de su rol. La pantalla de registro no ofrece los roles Inspector ni Administrador. |
