### CU-11 · Publicar material

| **Módulo · Prioridad** | M06 · SegundaVida Pereira · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | Almacenamiento de archivos (vía CU-47) |
| **Requisitos** | RF-06, RN-05, RN-06 |
| **Descripción** | Permite publicar materiales o herramientas sobrantes para vender, intercambiar o alquilar a vecinos, con imágenes, descripción, cantidad, estado, ubicación aproximada, modalidad y precio cuando aplique. |
| **Precondiciones** | El usuario tiene sesión vigente. Existe conectividad (SegundaVida no opera sin conexión en la v1.0). |
| **Disparador** | El usuario pulsa «Publicar» en SegundaVida. |
| **Flujo principal** | **1.** El usuario elige la modalidad: venta, intercambio o alquiler.  **2.** El usuario ingresa descripción, categoría, cantidad y estado (nuevo, buen estado o usado).  **3.** Si la modalidad lo requiere, ingresa el precio (o el costo por día en alquiler).  **4.** El usuario adjunta las imágenes mediante CU-47.  **5.** El usuario confirma o ajusta la ubicación aproximada (a nivel de zona o barrio, nunca la dirección exacta).  **6.** El sistema valida los datos obligatorios.  **7.** El sistema publica el material y lo hace visible en las búsquedas (CU-12).  **8.** El sistema confirma la publicación. |
| **Flujos alternativos** | **A1** Gestionar publicaciones propias: el usuario edita, pausa, marca como entregado o cierra una publicación.  **A2** Modo Emergencia activo: la publicación no genera comisión y su inventario puede convertirse en oferta de ayuda (CU-41). |
| **Excepciones** | **E1** Imagen no válida o que excede los límites: CU-47 la rechaza y el usuario debe cambiarla.  **E2** Datos obligatorios incompletos: el sistema marca los campos faltantes.  **E3** Publicación reportada por contenido inapropiado: pasa a revisión del Administrador (CU-16). |
| **Postcondiciones** | La publicación existe y es visible con su ubicación aproximada. El inventario queda disponible para una posible conversión a banco de ayudas. |
| **Reglas de negocio** | La ubicación publicada es aproximada para proteger la privacidad del vendedor. El modelo de comisión se prepara en los datos, pero no se cobra en la v1.0. |
| **Relaciones** | «include» CU-47 (adjuntar archivos). Su inventario alimenta CU-41. |
| **Criterios de aceptación** | Un usuario publica un material con fotos y precio, y la publicación aparece en las búsquedas con su distancia aproximada. |
