### CU-13 · Solicitar alquiler de herramienta

| **Módulo · Prioridad** | M06 · SegundaVida Pereira · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano (solicitante) |
| **Actores secundarios** | — |
| **Requisitos** | RF-08 |
| **Descripción** | Permite solicitar y reservar una herramienta indicando fechas y costo. El propietario responde en CU-14. |
| **Precondiciones** | El usuario tiene sesión vigente. La herramienta está publicada en modalidad alquiler y activa. |
| **Disparador** | El usuario pulsa «Solicitar alquiler» en el detalle de una herramienta. |
| **Flujo principal** | **1.** El usuario selecciona las fechas de inicio y fin.  **2.** El sistema verifica la disponibilidad de la herramienta para esas fechas.  **3.** El sistema calcula y muestra el costo según el valor por día.  **4.** El usuario confirma la solicitud.  **5.** El sistema registra la solicitud en estado «Pendiente» y notifica al propietario.  **6.** El propietario responde (CU-14) y el sistema notifica el resultado al solicitante.  **7.** Si fue aceptada, la reserva queda registrada con sus fechas y costo. |
| **Flujos alternativos** | **A1** El propietario rechaza la solicitud: el sistema notifica al solicitante, que puede buscar otra herramienta.  **A2** El solicitante cancela la solicitud antes de que sea aceptada. |
| **Excepciones** | **E1** Fechas no disponibles o ya reservadas: el sistema propone otras fechas.  **E2** La publicación fue pausada o cerrada: el sistema lo informa.  **E3** El usuario intenta alquilar su propia herramienta: el sistema lo impide. |
| **Postcondiciones** | Existe una solicitud o reserva con fechas, costo y estado, y el propietario fue notificado. |
| **Reglas de negocio** | No hay pagos en línea en la v1.0: el costo se registra y el pago se acuerda entre las partes. En Modo Emergencia no se cobran comisiones. |
| **Relaciones** | Continúa en CU-14 (respuesta del propietario) y en CU-15 (calificación). |
| **Criterios de aceptación** | Una herramienta puede reservarse para unas fechas y el propietario recibe la solicitud. |
