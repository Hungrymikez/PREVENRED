### CU-17 · Gestionar perfil de técnico

| **Módulo · Prioridad** | M07 · OficiosYa Pereira · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Técnico / Voluntario |
| **Actores secundarios** | Almacenamiento de archivos |
| **Requisitos** | RF-10, RN-05, RN-06 |
| **Descripción** | Permite al técnico registrar y mantener su identidad, especialidad, experiencia, portafolio, zona de trabajo y disponibilidad. El perfil lo verifica un Administrador (CU-18). |
| **Precondiciones** | El usuario tiene una cuenta de Técnico / Voluntario con sesión vigente. |
| **Disparador** | El técnico abre su perfil profesional. |
| **Flujo principal** | **1.** El sistema muestra el perfil con el estado de verificación vigente.  **2.** El técnico completa o edita identidad, especialidad, años de experiencia, portafolio y zona de trabajo.  **3.** El técnico adjunta los documentos requeridos para la verificación.  **4.** El técnico indica su disponibilidad (hoy, mañana o esta semana).  **5.** El sistema valida los datos obligatorios y los archivos.  **6.** El sistema guarda el perfil; si cambiaron datos de verificación, lo deja en «Pendiente» y lo envía a la cola de CU-18. |
| **Flujos alternativos** | **A1** Actualizar solo la disponibilidad o el portafolio: no reinicia el proceso de verificación.  **A2** Con la emergencia activa, el perfil habilita la postulación como voluntario (CU-44). |
| **Excepciones** | **E1** Documento ilegible o no permitido: el sistema lo rechaza.  **E2** Datos obligatorios incompletos: el sistema marca los campos faltantes.  **E3** Perfil suspendido: el sistema permite consultarlo pero no editarlo hasta resolver la suspensión. |
| **Postcondiciones** | El perfil queda guardado y, si corresponde, pendiente de verificación. |
| **Reglas de negocio** | Los documentos personales se protegen con control de acceso y retención limitada (RN-05, RN-06). Solo los técnicos verificados son visibles en OficiosYa. |
| **Relaciones** | Su revisión se hace en CU-18. Aporta perfiles a CU-43 y CU-44 en emergencia. |
| **Criterios de aceptación** | El técnico guarda su perfil y este queda «Pendiente» hasta que un administrador lo verifique. |
