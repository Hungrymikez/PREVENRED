### CU-20 · Solicitar cotización con evidencia

| **Módulo · Prioridad** | M07 · OficiosYa Pereira · Prioridad Media · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | Almacenamiento de archivos (vía CU-47) |
| **Requisitos** | RF-12, RN-06 |
| **Descripción** | Permite enviar a un técnico una descripción del problema con fotografías o un video de hasta 30 segundos para que prepare una cotización. |
| **Precondiciones** | El usuario tiene sesión vigente. El técnico está verificado y activo. |
| **Disparador** | El usuario pulsa «Pedir cotización» en el perfil de un técnico. |
| **Flujo principal** | **1.** El usuario describe el problema a resolver.  **2.** El usuario adjunta fotografías o un video de hasta 30 segundos mediante CU-47.  **3.** El sistema valida los datos y la evidencia.  **4.** El usuario confirma el envío.  **5.** El sistema registra la solicitud en estado «Enviada» y notifica al técnico.  **6.** Cuando el técnico responde (CU-21), el sistema notifica al ciudadano y le muestra la propuesta. |
| **Flujos alternativos** | **A1** Si el video no se habilita en la v1.0, la solicitud se envía solo con fotografías (ver observación O-12).  **A2** El usuario cancela la solicitud antes de que el técnico responda. |
| **Excepciones** | **E1** Video con duración superior a 30 s o que excede el almacenamiento: CU-47 lo rechaza.  **E2** La evidencia es retirada por moderación: el sistema avisa y pide reemplazarla.  **E3** El técnico dejó de estar disponible o fue suspendido: el sistema lo informa. |
| **Postcondiciones** | La solicitud de cotización queda registrada y asociada al técnico. |
| **Reglas de negocio** | Video de hasta 30 s, sujeto a límites de almacenamiento y moderación (RF-12). La contratación y el pago no se gestionan dentro de la plataforma. |
| **Relaciones** | «include» CU-47. Responde CU-21. El contenido reportado se modera en CU-16. |
| **Criterios de aceptación** | Un ciudadano envía una solicitud con fotos y el técnico la recibe con la evidencia. |
