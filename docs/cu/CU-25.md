### CU-25 · Procesar análisis NLP

| **Módulo · Prioridad** | M08 · Mente Resiliente · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Servicio NLP/IA |
| **Actores secundarios** | — |
| **Requisitos** | RF-15, RF-16, RN-03, RNF-04 |
| **Descripción** | Anonimiza los textos de bienestar y obtiene patrones emocionales agregados por barrio y periodo, documentando el modelo, su versión, la fecha y las métricas de validación. |
| **Precondiciones** | Existen respuestas de CU-23 pendientes de análisis. El modelo fue evaluado y está autorizado para uso operativo. |
| **Disparador** | El proceso de análisis se ejecuta sobre las respuestas recibidas. |
| **Flujo principal** | **1.** El sistema selecciona las respuestas pendientes de análisis.  **2.** El sistema aplica minimización y protección de datos personales: elimina o enmascara datos identificables del texto.  **3.** El sistema envía los textos minimizados al componente de análisis.  **4.** El componente identifica los patrones emocionales definidos por el proyecto.  **5.** El sistema agrega los resultados por barrio o comuna y por periodo.  **6.** El sistema registra el modelo, su versión, la fecha de procesamiento y las métricas de validación.  **7.** El sistema deja los resultados agregados disponibles para CU-26 y para la capa de bienestar del mapa. |
| **Flujos alternativos** | **A1** Revisión humana: los resultados se contrastan periódicamente con una revisión humana del modelo. |
| **Excepciones** | **E1** El servicio de NLP no está disponible: las respuestas quedan en cola; el registro de bienestar se mantiene sin análisis.  **E2** El modelo no tiene validación vigente: no se publican resultados.  **E3** El texto no puede minimizarse: se excluye del análisis. |
| **Postcondiciones** | Hay resultados agregados con modelo, versión, fecha y métricas documentados. No se expone ningún resultado individual. |
| **Reglas de negocio** | RNF-04: el pipeline minimiza y protege los datos personales antes del análisis y documenta qué se conserva. RN-03: uso solo agregado; no es un diagnóstico clínico. |
| **Relaciones** | Procesa lo recibido en CU-23. Sus resultados los consulta CU-26. |
| **Criterios de aceptación** | Cada ejecución del análisis deja registrado el modelo, su versión, la fecha y las métricas. Ningún resultado se muestra a nivel de persona. |
