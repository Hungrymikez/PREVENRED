### CU-27 · Solicitar apoyo profesional

| **Módulo · Prioridad** | M08 · Mente Resiliente · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | — |
| **Requisitos** | RF-18 |
| **Descripción** | Permite pedir orientación o contacto con profesionales autorizados, o consultar la línea de apoyo oficial. |
| **Precondiciones** | El usuario tiene sesión vigente. |
| **Disparador** | El usuario pulsa «¿Necesitas hablar con alguien ahora?» o «Contactar a un profesional». |
| **Flujo principal** | **1.** El sistema muestra las opciones de orientación disponibles: línea de apoyo oficial y contacto con profesionales autorizados.  **2.** El usuario elige una opción.  **3.** El sistema registra una solicitud mínima.  **4.** El sistema presenta la información de contacto o conecta con el servicio definido por la autoridad.  **5.** El sistema confirma la solicitud. |
| **Flujos alternativos** | **A1** El usuario expresa una situación de crisis: se activa CU-28.  **A2** La solicitud nace de «Pedir ayuda» con necesidad de apoyo emocional (CU-31). |
| **Excepciones** | **E1** La línea de apoyo oficial aún no está definida: el sistema muestra un mensaje provisional con la indicación de la autoridad.  **E2** No hay profesionales disponibles: el sistema muestra la línea de apoyo y reintenta más tarde. |
| **Postcondiciones** | El usuario tiene una vía de orientación y la solicitud mínima queda registrada. |
| **Reglas de negocio** | No hay teleconsulta, chatbot terapéutico ni seguimiento clínico dentro de la plataforma. El número oficial de la línea de apoyo está por confirmar. |
| **Relaciones** | «extend» desde CU-28 si se detecta una expresión de crisis. |
| **Criterios de aceptación** | El botón de apoyo abre el flujo de orientación definido por la autoridad. |
