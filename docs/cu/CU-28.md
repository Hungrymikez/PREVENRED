### CU-28 · Activar flujo de atención de crisis

| **Módulo · Prioridad** | M08 · Mente Resiliente · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Sistema (extiende CU-23 y CU-27) |
| **Actores secundarios** | — |
| **Requisitos** | RF-18, RN-03 |
| **Descripción** | Ante una expresión de crisis, interrumpe el flujo normal y presenta el flujo de atención definido por la autoridad competente, sin presentar el NLP como diagnóstico. |
| **Precondiciones** | Se detectó una expresión de crisis durante CU-23 o CU-27. La autoridad definió el flujo de atención ante crisis. |
| **Disparador** | El sistema detecta una expresión de crisis. |
| **Flujo principal** | **1.** El sistema interrumpe el flujo en curso.  **2.** El sistema muestra un mensaje empático que no etiqueta ni diagnostica a la persona.  **3.** El sistema ofrece de inmediato las opciones de ayuda: línea de apoyo oficial y contacto con un profesional autorizado.  **4.** El sistema activa el flujo de atención definido por la autoridad.  **5.** El sistema registra de forma mínima que el flujo fue activado.  **6.** El usuario decide cómo continuar. |
| **Flujos alternativos** | **A1** El usuario pide contactar a un profesional: continúa en CU-27. |
| **Excepciones** | **E1** El flujo de la autoridad aún no está configurado: el sistema muestra un mensaje base con las vías de ayuda disponibles. |
| **Postcondiciones** | La persona recibió opciones de ayuda y el flujo de atención quedó activado. |
| **Reglas de negocio** | El resultado de NLP no se presenta como diagnóstico (RF-18, RN-03). El flujo y los datos que se comparten los define la autoridad competente (ver observación O-06). |
| **Relaciones** | «extend» de CU-23 y de CU-27 (solo si se detecta una expresión de crisis). |
| **Criterios de aceptación** | Ante una expresión de crisis, el usuario ve el flujo definido por la autoridad y ningún mensaje de diagnóstico. |
