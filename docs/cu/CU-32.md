### CU-32 · Consultar estado de mis casos

| **Módulo · Prioridad** | M09 · Reporte de Incidentes y Solicitudes de Ayuda · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | — |
| **Requisitos** | RF-22, RF-24 |
| **Descripción** | Permite consultar el estado autorizado de los casos propios (reportes de daño, de vías y solicitudes de ayuda) mediante su identificador. |
| **Precondiciones** | El usuario tiene sesión vigente. Tiene al menos un caso registrado. |
| **Disparador** | El usuario abre «Mis casos» o ingresa un identificador de caso. |
| **Flujo principal** | **1.** El sistema lista los casos propios con su identificador y estado.  **2.** El usuario selecciona un caso.  **3.** El sistema muestra el estado autorizado (Reportado, En revisión, Asignado, En atención o Resuelto/Despejado) y el historial de cambios con su fecha.  **4.** Para una vivienda inspeccionada, muestra el estado autorizado del caso según el resultado. |
| **Flujos alternativos** | **A1** El usuario busca por identificador y el sistema abre el caso si le pertenece. |
| **Excepciones** | **E1** El identificador no existe o no pertenece al usuario: el sistema responde sin revelar si el caso existe.  **E2** Sin conectividad: el sistema muestra el último estado sincronizado indicando su fecha. |
| **Postcondiciones** | El usuario conoce el estado de su caso. |
| **Reglas de negocio** | Solo se muestra el estado autorizado, no datos internos de gestión. Cada cambio de estado se notifica al ciudadano. |
| **Relaciones** | Consulta lo creado en CU-29, CU-30 y CU-31, y gestionado en CU-39 y CU-36. |
| **Criterios de aceptación** | Un ciudadano consulta el estado de su caso por identificador y ve únicamente información autorizada. |
