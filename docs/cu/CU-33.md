### CU-33 · Ofrecer ayuda o donación

| **Módulo · Prioridad** | M12 · Banco de Ayudas y Matching · Prioridad Alta · Etapa 3 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | — |
| **Requisitos** | RF-27, RF-26, RN-05 |
| **Descripción** | Permite registrar una oferta de recursos (materiales, herramientas u otros bienes) para atender las necesidades de la emergencia. |
| **Precondiciones** | El Modo Emergencia está activo. El usuario tiene sesión vigente. |
| **Disparador** | El usuario pulsa «Ofrecer ayuda» en la pantalla de emergencia. |
| **Flujo principal** | **1.** El usuario elige el tipo de recurso que ofrece.  **2.** El usuario indica cantidad, estado y fecha de disponibilidad.  **3.** El usuario indica su ubicación aproximada y las restricciones logísticas (por ejemplo, si puede entregar o solo se recoge) (ver observación O-05).  **4.** El usuario envía la oferta.  **5.** El sistema registra la oferta en estado «Disponible» y confirma. |
| **Flujos alternativos** | **A1** El usuario ofrece ítems ya publicados en SegundaVida: el sistema los vincula y conserva su origen (RF-26). |
| **Excepciones** | **E1** El usuario intenta ofrecer dinero: el sistema lo impide, pues las donaciones monetarias están fuera de alcance.  **E2** Datos incompletos: el sistema pide completarlos. |
| **Postcondiciones** | Hay una oferta registrada y disponible para el matching (CU-42). |
| **Reglas de negocio** | No se gestionan donaciones monetarias ni logística de transporte en la v1.0. No se cobran comisiones en Modo Emergencia. |
| **Relaciones** | Alimenta CU-41 y CU-42. |
| **Criterios de aceptación** | Un ciudadano registra una oferta de herramientas y esta aparece disponible para el matching. |
