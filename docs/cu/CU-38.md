### CU-38 · Consultar asignaciones

| **Módulo · Prioridad** | M13 y M10 · Voluntariado / Censo de Inmuebles e Inspección · Prioridad Alta · Etapa 3 |
| --- | --- |
| **Actor primario** | Inspector; Técnico / Voluntario |
| **Actores secundarios** | — |
| **Requisitos** | RF-28, RF-24 |
| **Descripción** | Permite ver las inspecciones o solicitudes de apoyo asignadas, con el detalle necesario para atenderlas. |
| **Precondiciones** | El usuario tiene sesión vigente. El Modo Emergencia está activo y hay asignaciones vigentes. |
| **Disparador** | El usuario abre «Asignaciones» o recibe el aviso de una nueva. |
| **Flujo principal** | **1.** El sistema lista las asignaciones vigentes con identificador, tipo, zona, prioridad y estado.  **2.** El usuario selecciona una asignación.  **3.** El sistema muestra el detalle autorizado: descripción, ubicación y evidencias del reporte.  **4.** El inspector puede iniciar el censo o la inspección (CU-34 o CU-36); el voluntario o técnico puede ver sus indicaciones. |
| **Flujos alternativos** | **A1** El inspector abre la ubicación en el mapa (CU-40).  **A2** Sin conectividad: el sistema muestra las asignaciones descargadas hasta la última sincronización, con su fecha. |
| **Excepciones** | **E1** La asignación fue reasignada o cancelada mientras se consultaba: el sistema lo informa y actualiza la lista.  **E2** No hay asignaciones: el sistema lo informa. |
| **Postcondiciones** | El usuario conoce sus asignaciones vigentes. |
| **Reglas de negocio** | Cada usuario solo ve lo asignado a él. La ubicación del voluntario se comparte únicamente mientras esté asignado. |
| **Relaciones** | Consulta lo asignado en CU-39 y CU-43. Un voluntario acepta una movilización en CU-44. |
| **Criterios de aceptación** | Un inspector ve únicamente sus inspecciones asignadas y puede iniciarlas. |
