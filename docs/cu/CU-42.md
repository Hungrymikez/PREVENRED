### CU-42 · Ejecutar matching de donaciones

| **Módulo · Prioridad** | M12 · Banco de Ayudas y Matching · Prioridad Alta · Etapa 3 |
| --- | --- |
| **Actor primario** | Administrador |
| **Actores secundarios** | — |
| **Requisitos** | RF-27, RF-05 |
| **Descripción** | Relaciona ofertas y necesidades según tipo, cantidad, ubicación, prioridad, fecha de disponibilidad y restricciones logísticas. El sistema propone coincidencias y una persona autorizada confirma la asignación. |
| **Precondiciones** | El Modo Emergencia está activo. Existen ofertas disponibles y necesidades abiertas. |
| **Disparador** | El administrador abre «Matching» o solicita actualizar las coincidencias. |
| **Flujo principal** | **1.** El sistema toma las ofertas disponibles y las necesidades abiertas.  **2.** El sistema aplica las reglas configuradas: tipo, cantidad, cercanía, prioridad, disponibilidad y restricciones logísticas.  **3.** El sistema genera las coincidencias propuestas, ordenadas por pertinencia.  **4.** El administrador revisa cada coincidencia.  **5.** El administrador confirma, modifica o rechaza.  **6.** Al confirmar, el sistema crea la asignación en estado «Confirmado» y reserva el inventario.  **7.** El sistema notifica al oferente y al solicitante.  **8.** El sistema registra la asignación en auditoría (CU-05).  **9.** El seguimiento avanza a «Entregado» y «Cerrado» y el inventario se actualiza. |
| **Flujos alternativos** | **A1** Cantidad insuficiente: el sistema propone una asignación parcial y mantiene abierta la necesidad.  **A2** Sin coincidencias: la necesidad queda en espera hasta que aparezcan nuevas ofertas. |
| **Excepciones** | **E1** La oferta ya fue asignada a otra necesidad: el sistema la excluye y recalcula.  **E2** La necesidad fue cancelada: el sistema retira la coincidencia.  **E3** Falta la ubicación de una oferta o necesidad: no se calcula la cercanía y se avisa. |
| **Postcondiciones** | La asignación queda registrada y auditada. El inventario refleja lo comprometido. |
| **Reglas de negocio** | Las coincidencias las propone el sistema; la asignación final la confirma una persona autorizada. Toda asignación y donación queda en la auditoría. No se cobran comisiones en Modo Emergencia. |
| **Relaciones** | «include» CU-05. Usa ofertas de CU-33 y CU-41 y necesidades de CU-31. |
| **Criterios de aceptación** | Dadas ofertas y necesidades compatibles, el sistema genera coincidencias según las reglas configuradas y registra la asignación. |
