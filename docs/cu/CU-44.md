### CU-44 · Postularse como voluntario

| **Módulo · Prioridad** | M13 · Voluntariado · Prioridad Alta · Etapa 3 |
| --- | --- |
| **Actor primario** | Técnico / Voluntario |
| **Actores secundarios** | — |
| **Requisitos** | RF-28, RF-10 |
| **Descripción** | Permite a un técnico o voluntario postularse, o aceptar ser movilizado, durante una emergencia según su perfil y autorización. |
| **Precondiciones** | El usuario tiene un perfil registrado (CU-17) y sesión vigente. El Modo Emergencia está activo (en Modo Cotidiano solo se mantiene el registro y el perfil). |
| **Disparador** | El usuario recibe una convocatoria (CU-07) o abre «Voluntariado». |
| **Flujo principal** | **1.** El sistema muestra la convocatoria o la opción de postularse.  **2.** El usuario confirma o actualiza habilidades, disponibilidad, ubicación aproximada y certificaciones.  **3.** El usuario confirma su postulación.  **4.** El sistema valida el perfil y la autorización vigente.  **5.** El sistema registra la postulación con estado «Disponible» y avisa al coordinador.  **6.** Si es asignado (CU-43), el usuario recibe la asignación y la acepta; el estado pasa a «En campo». |
| **Flujos alternativos** | **A1** El usuario se retira o se marca como «No disponible».  **A2** El usuario declina una asignación: el sistema lo informa al coordinador. |
| **Excepciones** | **E1** El usuario no tiene perfil: el sistema lo lleva a completarlo (CU-17).  **E2** El usuario no está autorizado: el sistema no permite la postulación. |
| **Postcondiciones** | El usuario figura en la bolsa con su estado de disponibilidad. |
| **Reglas de negocio** | Solo se movilizan personas con rol y autorización vigentes. La ubicación se comparte únicamente mientras el voluntario esté asignado. |
| **Relaciones** | Responde a convocatorias de CU-43. Usa el perfil de CU-17 y la notificación de CU-07. |
| **Criterios de aceptación** | Un técnico se postula y aparece disponible en la bolsa de voluntariado del coordinador. |
