### CU-47 · Adjuntar archivos multimedia

| **Módulo · Prioridad** | M09 y M10 · Reporte de Incidentes y Solicitudes de Ayuda / Censo de Inmuebles e Inspección · Prioridad Crítica · Etapa 2 y 3 |
| --- | --- |
| **Actor primario** | Sistema (invocado por otros casos de uso) |
| **Actores secundarios** | Almacenamiento de archivos |
| **Requisitos** | RF-06, RF-12, RF-19, RF-23, RNF-05, RNF-14, RN-06 |
| **Descripción** | Sube fotografías o videos con validación, cifrado y control de acceso. Es un caso de apoyo que usan la publicación de materiales, la cotización, los reportes de daño y de vías y el censo. |
| **Precondiciones** | Un caso invocante solicitó adjuntar un archivo. El usuario concedió los permisos de cámara o galería. |
| **Disparador** | CU-11, CU-20, CU-29, CU-30 o CU-34 solicitan adjuntar un archivo. |
| **Flujo principal** | **1.** El usuario captura o selecciona el archivo.  **2.** El sistema valida el tipo, el tamaño y, en videos de cotización, la duración máxima de 30 segundos.  **3.** El sistema verifica la seguridad del archivo (validación o antivirus).  **4.** El sistema sube el archivo al almacenamiento cifrado con control de acceso.  **5.** El sistema obtiene la referencia del archivo (con URL temporal para su consulta).  **6.** El sistema vincula el archivo al registro del caso invocante y muestra una miniatura. |
| **Flujos alternativos** | **A1** Varios archivos: el usuario adjunta hasta el límite definido para cada caso de uso.  **A2** El usuario elimina un archivo antes de enviar el registro.  **A3** Sin conectividad: el archivo se conserva en la cola local y se sube al sincronizar (CU-37). |
| **Excepciones** | **E1** Tipo de archivo no permitido: el sistema lo rechaza.  **E2** El archivo supera los límites de tamaño o duración: el sistema lo rechaza y lo informa.  **E3** El archivo no supera la validación de seguridad: el sistema lo rechaza.  **E4** El almacenamiento no está disponible: el sistema reintenta y conserva el archivo localmente. |
| **Postcondiciones** | El archivo queda almacenado, cifrado y vinculado al registro. |
| **Reglas de negocio** | Las fotografías, videos y documentos se almacenan con control de acceso y políticas de retención (RN-06). El acceso a los archivos se hace con URL temporales. |
| **Relaciones** | «include» desde CU-11, CU-20, CU-29, CU-30 y CU-34. Se sugiere sumarlo a CU-17 y CU-36 (ver observación O-04). |
| **Criterios de aceptación** | Un archivo con tipo, tamaño y duración válidos se almacena cifrado y queda vinculado a su registro; uno no válido se rechaza. |
