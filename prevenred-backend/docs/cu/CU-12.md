### CU-12 · Buscar materiales por ubicación

| **Módulo · Prioridad** | M06 · SegundaVida Pereira · Prioridad Alta · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | GPS / Mapas (vía CU-48) |
| **Requisitos** | RF-07, RNF-03 |
| **Descripción** | Permite explorar materiales y herramientas por pestañas (Comprar, Intercambiar, Alquilar) y filtrar por categoría, condición, precio y radio de distancia respecto a una ubicación autorizada. |
| **Precondiciones** | El usuario tiene sesión vigente. |
| **Disparador** | El usuario abre «Materiales» en SegundaVida. |
| **Flujo principal** | **1.** El usuario elige la pestaña Comprar, Intercambiar o Alquilar.  **2.** El sistema obtiene la ubicación del usuario mediante CU-48.  **3.** El usuario aplica filtros: categoría, estado, precio y radio de distancia.  **4.** El sistema ejecuta la consulta geoespacial.  **5.** El sistema muestra las tarjetas con foto, estado, distancia y precio.  **6.** El usuario abre el detalle de una publicación.  **7.** El sistema muestra la descripción completa, el estado y la ubicación aproximada. |
| **Flujos alternativos** | **A1** El usuario no concede el permiso de ubicación: puede buscar sin filtro de distancia o indicar una zona manualmente.  **A2** La publicación es una herramienta en alquiler: el usuario puede continuar con CU-13. |
| **Excepciones** | **E1** Sin resultados: el sistema sugiere ampliar el radio o quitar filtros.  **E2** El servicio de mapas no está disponible: el sistema muestra los resultados en lista, sin distancia. |
| **Postcondiciones** | El usuario obtiene un listado ordenado y filtrado de publicaciones. |
| **Reglas de negocio** | Las consultas geoespaciales críticas deben responder en menos de 400 ms bajo la carga definida (RNF-03). Solo se usa ubicación autorizada por el usuario. |
| **Relaciones** | «include» CU-48 (obtener ubicación). Puede continuar en CU-13. |
| **Criterios de aceptación** | Un usuario filtra por distancia y categoría y obtiene publicaciones cercanas con su distancia. |
