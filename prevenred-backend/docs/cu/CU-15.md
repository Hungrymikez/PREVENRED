### CU-15 · Calificar y reseñar

| **Módulo · Prioridad** | M06 y M07 · SegundaVida Pereira / OficiosYa Pereira · Prioridad Media · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | — |
| **Requisitos** | RF-09 |
| **Descripción** | Permite calificar y comentar a la contraparte una vez completada una transacción (alquiler o intercambio en SegundaVida, o un servicio de OficiosYa), alimentando la reputación comunitaria. |
| **Precondiciones** | La transacción o el servicio está marcado como completado. El usuario no ha calificado aún esa transacción. |
| **Disparador** | El sistema habilita la calificación tras completarse la transacción, o el usuario la abre desde su historial. |
| **Flujo principal** | **1.** El usuario abre la calificación pendiente.  **2.** El usuario selecciona una puntuación.  **3.** El usuario escribe un comentario (opcional).  **4.** El sistema valida la puntuación y revisa que el contenido cumpla las reglas básicas contra abuso.  **5.** El sistema publica la reseña y actualiza la reputación de la contraparte. |
| **Flujos alternativos** | **A1** El usuario omite la calificación: puede hacerla después desde su historial.  **A2** Calificación de un técnico al finalizar un servicio de OficiosYa: sigue el mismo flujo y alimenta el perfil del técnico.  **A3** El usuario reporta una reseña ajena como inapropiada: pasa a CU-16. |
| **Excepciones** | **E1** La transacción no está completada: el sistema no permite calificar.  **E2** Ya existe una calificación del usuario para esa transacción: el sistema lo informa.  **E3** Contenido inapropiado: el sistema lo bloquea o lo envía a revisión. |
| **Postcondiciones** | La reseña queda asociada a la transacción y a la contraparte; la reputación se actualiza. |
| **Reglas de negocio** | Una reseña solo puede emitirse tras una transacción completada. Reputación compartida entre SegundaVida y OficiosYa. |
| **Relaciones** | Depende de CU-14 (SegundaVida) y de la finalización de un servicio (OficiosYa). Las reseñas reportadas se revisan en CU-16. |
| **Criterios de aceptación** | Un usuario califica a la contraparte solo después de una transacción completada y la reputación se actualiza. |
