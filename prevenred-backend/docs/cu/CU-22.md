### CU-22 · Contactar técnico por WhatsApp

| **Módulo · Prioridad** | M07 · OficiosYa Pereira · Prioridad Media · Etapa 2 |
| --- | --- |
| **Actor primario** | Ciudadano |
| **Actores secundarios** | WhatsApp |
| **Requisitos** | RF-13, RN-05 |
| **Descripción** | Permite abrir una conversación por WhatsApp con un técnico, con la autorización previa del usuario. La plataforma conserva solo el registro mínimo de la solicitud. |
| **Precondiciones** | El usuario consulta el perfil de un técnico verificado (CU-19). El técnico tiene habilitado el contacto por WhatsApp. |
| **Disparador** | El usuario pulsa el botón «WhatsApp» del técnico. |
| **Flujo principal** | **1.** El sistema informa qué datos se compartirán y solicita la autorización del usuario.  **2.** El usuario autoriza el contacto.  **3.** El sistema registra la solicitud mínima: usuario, técnico y fecha.  **4.** El sistema genera un enlace seguro con un mensaje inicial, sin datos innecesarios.  **5.** El sistema abre WhatsApp con el enlace.  **6.** La conversación continúa fuera de la plataforma. |
| **Flujos alternativos** | **A1** El usuario no autoriza: no se genera enlace y puede continuar con CU-20.  **A2** WhatsApp no está instalado: el sistema ofrece pedir cotización dentro de la plataforma. |
| **Excepciones** | **E1** El técnico no tiene un número válido: el sistema lo informa.  **E2** Falla al generar o abrir el enlace: el sistema permite reintentar. |
| **Postcondiciones** | Queda registrado el contacto mínimo y el usuario puede conversar con el técnico. |
| **Reglas de negocio** | El enlace solo se genera con consentimiento y sin exponer datos innecesarios (RN-05). No se usa mensajería masiva automatizada por WhatsApp Business. |
| **Relaciones** | «extend» de CU-19 (solo si el usuario autoriza el contacto). |
| **Criterios de aceptación** | El enlace de WhatsApp solo se genera tras la autorización del usuario y la plataforma conserva únicamente el registro mínimo. |
