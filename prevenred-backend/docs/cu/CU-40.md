### CU-40 · Consultar mapa multicapa

| **Módulo · Prioridad** | M11 · Mapa Multicapa · Prioridad Crítica · Etapa 3 |
| --- | --- |
| **Actor primario** | Administrador; Inspector |
| **Actores secundarios** | GPS / Mapas |
| **Requisitos** | RF-25, RNF-03, RN-05 |
| **Descripción** | Permite ver las capas autorizadas (reportes, zonas de riesgo, infraestructura crítica, red vial y bienestar por barrio) y activarlas o desactivarlas sin perder la posición del mapa. |
| **Precondiciones** | El usuario tiene sesión vigente. Existen capas configuradas (CU-10). |
| **Disparador** | El usuario abre el mapa multicapa. |
| **Flujo principal** | **1.** El sistema carga el mapa base y las capas autorizadas para el rol del usuario.  **2.** El usuario activa o desactiva capas.  **3.** El sistema actualiza la visualización conservando el centro y el zoom.  **4.** El usuario selecciona un elemento del mapa.  **5.** El sistema muestra una ventana con los datos del incidente y el enlace al caso.  **6.** El sistema muestra la fecha de actualización y el responsable de la fuente de cada capa. |
| **Flujos alternativos** | **A1** Vista simplificada «Cerca de ti» para Ciudadano y Técnico / Voluntario (ver observación O-15). |
| **Excepciones** | **E1** Una capa no está disponible: el sistema lo informa y mantiene el resto.  **E2** El servicio de mapas no responde: el sistema usa el caché controlado o informa.  **E3** Una capa está desactualizada: el sistema muestra la advertencia con su fecha. |
| **Postcondiciones** | El usuario ve la información geoespacial autorizada para su rol. |
| **Reglas de negocio** | Las capas de bienestar solo muestran datos agregados con umbral mínimo de población. La ubicación precisa de las personas la ven solo los roles autorizados. Las consultas geoespaciales críticas deben responder en menos de 400 ms (RNF-03). |
| **Relaciones** | Usa las capas de CU-10. Es apoyo de CU-39, CU-36 y CU-45. |
| **Criterios de aceptación** | El dashboard carga las capas autorizadas y permite activarlas y desactivarlas sin perder la ubicación del mapa. |
